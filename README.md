# D&D Toolkit — «Книга мастера»

Мобильный фэнтезийный справочник и набор генераторов для мастера D&D и других настольных ролевых игр. Рассчитан на телефон (Android, экраны 360–430 px), работает без сервера и без регистрации, умеет работать офлайн (PWA).

Дополнительно: счётчик найденных записей, копирование любой записи в буфер, избранное и настройки в `localStorage`.

Цены: 1 зм = 10 см = 100 мм (как в 5e). Все тексты собственные. Механики, придуманные автором, помечены «дом. правило» и не привязаны к конкретной редакции.

## Запуск

Нужен [Node.js](https://nodejs.org/) 18 или новее.

```bash
npm install
npm run dev        # режим разработки: адрес появится в терминале
npm run build      # production-сборка в папку dist/
npm run preview    # посмотреть собранную версию
```

Чтобы открыть с телефона во время разработки, подключите его к той же Wi-Fi сети и откройте адрес `Network`, который покажет `npm run dev`. (Офлайн-режим работает только в собранной версии по https или на localhost.)

## Публикация на GitHub Pages

1. Создайте новый репозиторий на GitHub и загрузите в него содержимое этой папки (вместе с папкой `.github`).
2. В репозитории откройте **Settings → Pages** и в поле **Source** выберите **GitHub Actions**.
3. Сделайте любой коммит в ветку `main` (или запустите workflow вручную во вкладке **Actions**). Сборка и публикация займут 1–2 минуты.
4. Приложение будет доступно по адресу `https://ваш-логин.github.io/название-репозитория/`.

Пути в проекте относительные (`base: './'`), поэтому дополнительно ничего настраивать не нужно.

## Установка на Android

Откройте опубликованный адрес в Chrome → меню ⋮ → **«Установить приложение»** (или «Добавить на главный экран»). После первого открытия приложение работает без интернета.

Обновление: после новой публикации закройте и снова откройте приложение — сервис-воркер подтянет свежую версию.

## Структура проекта

```
src/
  data/          ← ВСЕ данные (зелья, имена, артефакты…) — расширяйте здесь
  sections/      ← разделы и их настройки (configs.tsx)
  components/    ← общие компоненты (карточки, таблица, фильтры)
  lib/           ← localStorage, копирование, случайность, форматирование цен
  types.ts       ← типы данных
public/          ← manifest, service worker, иконки
.github/workflows/deploy.yml  ← автоматическая публикация на Pages
```

## Как добавить свои записи

Откройте нужный файл в `src/data/` и добавьте строку в массив, например в `potions.ts`:

```ts
P('Моё зелье', 'rare', 'Необычное', 12000, 'Что оно делает.', '1 час', true),
```

Параметры: название, редкость (`common`, `uncommon`, `rare`, `veryRare`, `legendary`), тип, цена **в медных монетах** (100 = 1 зм), эффект, длительность, признак домашнего правила. Остальные файлы устроены так же. Новые имена добавляются в массивы `male`, `female`, `neutral`, `surnames` в `src/data/names.ts`.

Новый раздел: создайте файл данных, добавьте настройку в `src/sections/configs.tsx` и вкладку в `src/App.tsx`.
